# Grijswaarde-meter

Mobielvriendelijke webpagina voor GitHub Pages. De pagina werkt als losse statische site: geen installatie, geen servercode en geen externe bibliotheken.

## Bestanden

- `index.html` is de webpagina.
- `manifest.webmanifest`, `sw.js` en `icon.svg` maken de pagina geschikt om op een iPhone aan het beginscherm toe te voegen.

## Op GitHub zetten

1. Maak een nieuwe GitHub-repository.
2. Kopieer de inhoud van deze map naar de root van die repository.
3. Ga in GitHub naar `Settings` > `Pages`.
4. Kies `Deploy from a branch`.
5. Kies branch `main` en map `/root`.
6. Open de GitHub Pages-link die GitHub toont.

## Op iPhone gebruiken

Open de GitHub Pages-link in Safari. Via de deelknop kun je `Zet op beginscherm` kiezen, zodat de meter als losse app opent.
