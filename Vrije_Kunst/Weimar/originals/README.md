# Originele afbeeldingen

Deze map bevat de oorspronkelijke, ongecomprimeerde afbeeldingen van de Weimar-catalogus.

De website verwijst uitsluitend naar de geoptimaliseerde versies in `Weimar/assets`. Daardoor kan deze map later worden verwijderd zonder dat afbeeldingen uit de online catalogus verdwijnen. Bewaar desgewenst eerst een externe back-up van de originelen.
